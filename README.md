# Weather Application in React

A simple and modern weather application built with React. This app allows users to check the current weather for any city, with a clean interface and responsive design.

## Features

- 🌤️ Search for current weather by city name
- 🔒 User authentication (login/signup)
- 🏠 Home page with weather details
- ⚡ Responsive UI
- 🎨 Styled with custom CSS

## Getting Started

### Prerequisites

- Node.js (v14 or above recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Weather-Application-in-React.git
   cd Weather-Application-in-React
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm start
   # or
   yarn start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

## Project Structure

```
src/
  App.js           # Main app component
  App.css          # App styles
  index.js         # Entry point
  index.css        # Global styles
  alertify.css     # Alert styles
  LoginComponent/  # Authentication components (login, signup, home)
  serviceWorker.js # Service worker for PWA
```

## Usage

- **Sign Up:** Create a new account using the signup page.
- **Login:** Access your account with your credentials.
- **Search Weather:** Enter a city name to get the current weather information.
